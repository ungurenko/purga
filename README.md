# ПУРГА

Бесконечный спуск на сноуборде сквозь метель. Браузерная 3D-игра на three.js.

## Как запустить

Нужен интернет (шрифты и three.js с CDN) и локальный сервер — модули браузер не откроет просто двойным кликом по файлу.

В папке проекта выполни одну команду:

```bash
python3 -m http.server 8080
```

Открой в браузере: [http://localhost:8080/](http://localhost:8080/)

## Управление

| Клавиши | Действие |
|---------|----------|
| ← → / A D | поворот, в воздухе — вращение |
| Space | прыжок |
| W / ↑ | группировка (разгон) |
| S / ↓ | тормоз · в воздухе — грэб |
| P / Esc | пауза |
| M | звук |
| R / Enter | старт / заново |

На телефоне появляются экранные кнопки.

## Структура

```
index.html          — экран (меню, HUD, пауза)
css/purga.css       — оформление
js/
  main.js           — точка входа
  game.js           — игровой цикл и правила
  scene.js          — 3D-мир, снег, свет
  rider.js          — модель и поза сноубордиста
  obstacles.js      — препятствия и спавн трассы
  theme.js          — день / ночь
  audio.js          — звук
  ui.js             — всплывающие надписи, комбо
  input.js          — клавиатура и тач
  state.js          — состояние и рекорд
  utils.js          — мелкие помощники
```

Старый однофайловый вариант лежит в `purga.html` (как запасная копия; основной вход — `index.html`).
